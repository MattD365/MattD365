### Projects

**[site-migration-auditor](https://github.com/MattD365/site-migration-auditor)** ·
Node.js, Playwright
Crawls a list of expected URLs after a CMS migration and produces a defect report a
content team can work from. Catches the failures a status-code sweep misses: bodies that
never arrived, images whose `src` did not survive, and slugs carrying unencoded
characters that make the origin 500 on articles that exist perfectly well. Zero runtime
dependencies, 23-assertion self-test, and a bundled fixture site with a `BREAK=1` mode so
you can watch the checks actually fail.

**[vcamp-launcher](https://github.com/MattD365/vcamp-launcher)** · Python, Tkinter
A single-file Windows desktop launcher styled like a 90s skinned media player. Scans a
folder, reads the README files it finds, and builds a button for every program it can
run. 2,500 lines, standard library only — copy one file to any Windows PC with Python
and it works.

**[web-scraping-toolkit](https://github.com/MattD365/web-scraping-toolkit)** · Python
Scrapers and data-cleaning scripts written for real jobs and kept because they turned out
to be reusable: college athletics data from Wikipedia and the NCAA, structured extraction
from PDF directories (with an OCR path for scanned pages), publisher logo discovery, and
spreadsheet enrichment.

**[mini-projects](https://github.com/MattD365/mini-projects)** · JavaScript
Three small things built for fun, each dependency-free: Wordle in the terminal (with the
duplicate-letter scoring most clones get wrong), Conway's Game of Life on a canvas, and a
Diceware passphrase generator with an honest entropy readout.
